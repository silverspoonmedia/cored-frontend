# Localization (i18n)

SPA-side localization: seven locale files, lazy chunks, RTL handling, and the guard chain. Normative rules: [.cursor/rules/i18n-locales.mdc](../.cursor/rules/i18n-locales.mdc) + the always-on [.cursor/rules/i18n-guardrail.mdc](../.cursor/rules/i18n-guardrail.mdc). Backend rules, canonical locale list: `monolith/docs/platform/localization.md`; settled terms and the domain glossary: `monolith/docs/platform/naming-conventions.md`.

| Need | Path |
|------|------|
| Locale files | `src/i18n/locales/{en,id,ja,ko,zh-CN,ar,ru}.json` (`en` is the source and the only eager chunk) |
| Shared instance + helpers | `src/i18n/index.ts` (`ensureLocale`, `translatableValue`, `normalizeTranslatableMap`) |
| Curation log | `src/i18n/curation-log.json` — one entry per curated key (`curated_at`, `surface`, `source`) |
| Duplicate-English policy | `scripts/lib/duplicate-english-allowlist.mjs` (locale-scoped) |
| Guard chain | `npm run check:i18n` → `check-i18n.mjs` + `check-i18n-usage.mjs` + `check-curation-log.mjs` |
| Cross-repo guards | `monolith/scripts/locale-{pack-parity,flat-pack-parity,glossary-scan,prose-scan,rawkey-scan}.php` |
| Conversion rules (PHP ↔ JSON, `zh_CN` ↔ `zh-CN`) | `i18n-locales.mdc` |

## In one screen

- **Patch keys, never dump files.** Grep the key in `en.json`, patch all seven, run `npm run check:i18n`.
- `check:i18n` proves parity, placeholders, duplicates and curation-log validity — it never proves the translation reads well. Read the changed string back on its own surface (register, calque, false friend, filler) before finishing.
- A key referenced from code but defined in no locale is a hard failure; unreachable keys are deleted, not kept — sweep them in the same change as the screen removal.
- `ar` switches the document to RTL; crossing directions reloads the page **after** `auth/locale` persists.
- Mirrored packs (`validation`, `http-statuses`, `auth`, `passwords`, `pagination`) must match the backend exactly, sigil aside. The SPA `actions.*` block is deliberately not a mirror.
- Cross-repo guards live in Monolith and cannot run in a lone SPA checkout — run `php artisan test --filter=Locale` from a Monolith checkout with this repo as a sibling when a mirrored pack or glossary term moves.

## Tooling

| Script | Purpose |
|--------|---------|
| `node scripts/i18n-pair-dump.mjs <locale> [--ns=<prefix>]` | Read-only `key \t EN \t <locale>` dump for review batches |
| `node scripts/apply-translations.mjs <locale> <map.json> [--surface=…] [--source=…] [--dry-run]` | Applies a batch and appends the curation-log entries (`leaf` for literal dotted settings labels) |
| `node scripts/i18n-duplicate-report.mjs` | Writes `i18n-duplicate-report.json`: inventory, classifications, stale-allowlist detection; `actionable_pairs` must stay 0 |
| `npm run check:i18n:usage` | Usage check alone — every literal `t()`/`tm()`/`te()` key under `src/**` resolves in `en.json` |
